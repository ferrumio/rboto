# S3

Use `rboto.s3()` or `rboto_s3.S3Client`. Install the S3 package following
[Getting started](../getting-started.md). Configure the client for your bucket's region.

## Upload bytes

```python
--8<-- "examples/docs/s3_upload.py"
```

This creates or replaces the object at that key. The body is bytes already held in
memory. Multipart upload methods are available as individual service operations.

## Download

```python
--8<-- "examples/docs/download.py"
```

A failed download may leave a partial destination file. See [Streaming](streaming.md)
for body ownership, `.read()`, and memory use.

## List every page

Each list call returns one page. Follow its continuation token:

```python
--8<-- "examples/docs/s3_pages.py"
```

Consume this helper with `async for`. The current Python API does not provide
automatic paginator objects.

Catch `NoSuchKeyError` for a missing-object response. Access policies can cause
an access-denied response instead. See [Errors](errors.md).
