# Code of conduct

Everyone participating in rboto's issues, pull requests, reviews, and other project
spaces is expected to treat others with respect.

- Keep feedback constructive and focused on the code or proposal.
- Explain disagreements with evidence and allow others to respond.
- Welcome questions and contributors with different experience levels.
- Do not harass, threaten, discriminate against, or insult other participants.
- Do not publish another person's private information without consent.

## Reporting and moderation

Report conduct concerns privately to the maintainer, Leandro Damascena, at
[leandro.damascena@gmail.com](mailto:leandro.damascena@gmail.com). Include links and
enough context to understand what happened. Reports will be handled with discretion.
For software vulnerabilities, use the separate process in [SECURITY.md](SECURITY.md).

The maintainer may request changes to a comment, remove inappropriate content, lock a
discussion, or restrict participation. The response should consider the severity,
impact, and repetition of the behavior. Participants may use the same private contact
to ask for clarification or reconsideration.
