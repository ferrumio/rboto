## Upload a stream

Pass any async iterable of `bytes` as the body. Chunks are sent as the producer yields
them, so the object never has to fit in memory. S3 needs the exact size before the first
byte, so pass `content_length`; rboto raises `ValueError` before sending if it is missing.

```python
--8<-- "examples/docs/s3_stream_upload.py"
```

A streamed body is consumed once. The SDK cannot replay it, so a transient failure during
the upload is reported instead of retried, and an exception raised by the producer
propagates from `put_object`. `upload_part` accepts the same body types, which keeps
multipart uploads incremental end to end. Multipart upload methods are available as
individual service operations.

## List every page

Each list call returns one page. Follow its continuation token:

```python
--8<-- "examples/docs/s3_pages.py"
```

Consume this helper with `async for`. The current Python API does not provide
automatic paginator objects.

Catch `NoSuchKeyError` for a missing-object response. Access policies can cause
an access-denied response instead. See [Errors](errors.md).
